# 📊 Excel Assignment 2 – Data Exploration & Cleaning

## 📌 Project Overview
This project focuses on exploring, cleaning, and transforming a Product Dataset using **Microsoft Excel**. The main goal is to improve data quality, accuracy, and consistency.

## 🎯 Tasks Performed
- Handled missing values.
- Corrected spelling errors using Find & Replace.
- Identified and removed duplicate records.
- Split and merged columns.
- Applied number and date formatting.
- Used Conditional Formatting to highlight important data.

## 🛠️ Tools Used
- Microsoft Excel
- Excel Formulas
- Data Cleaning Techniques
- Conditional Formatting

## 📈 Project Results
- Original Records: **34**
- Duplicate Records Removed: **3**
- Final Unique Records: **31**
- Missing Price Values Identified: **3**
- Missing Category Values Identified: **4**
- Corrected Category: **Electroni → Electronics**
